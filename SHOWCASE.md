# Showcase

**Project Name**
Hirono Archive - Katalog Figur Koleksi (Express & React Native)

**Description**
Hirono Archive adalah aplikasi katalog dan koleksi figur Hirono. Backend dibangun dengan Express.js dan Prisma ORM (SQLite), dilengkapi REST API, validasi input dengan express-validator, dan upload gambar dengan Multer. Aplikasi mobile dibuat dengan React Native (Expo) dan React Navigation. Fitur: menjelajahi seri, mencari figur, melihat detail, menambah/mengedit/menghapus figur beserta gambarnya, serta mengelola koleksi pribadi (jumlah dan kondisi).
